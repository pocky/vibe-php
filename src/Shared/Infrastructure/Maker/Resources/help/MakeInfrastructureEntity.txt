The <info>%command.name%</info> command generates a complete infrastructure entity
structure following DDD patterns.

<info>php %command.full_name% Blog Article</info>

This creates:
  * <comment>src/Blog/Infrastructure/Persistence/Doctrine/ORM/Entity/Article.php</comment>
    Doctrine entity with constructor injection

  * <comment>src/Blog/Infrastructure/Persistence/Doctrine/ORM/ArticleWriteRepository.php</comment>
    Write repository implementing domain interface

  * <comment>src/Blog/Domain/Article/Shared/Identifier/ArticleId.php</comment>
    Identifier class for entity

  * <comment>src/Blog/Domain/Article/Shared/Repository/ArticleWriteRepositoryInterface.php</comment>
    Domain write repository interface

  * <comment>src/Blog/Infrastructure/Identity/ArticleIdGenerator.php</comment>
    ID generator service using UUID v7

The entity features:
  * UUID v7 as primary key
  * Constructor injection pattern
  * Immutable timestamps (createdAt, updatedAt)
  * Proper Doctrine mappings
  * DDD naming conventions

  3. Implement domain aggregate if needed
