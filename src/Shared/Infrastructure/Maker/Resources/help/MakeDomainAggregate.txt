The <info>%command.name%</info> command generates a complete domain aggregate
structure following DDD patterns.

<info>php %command.full_name% Blog CreateArticle Article</info>

This creates:
  * <comment>src/Blog/Domain/Article/ArticleCreator.php</comment>
    Domain service for creating articles

  * <comment>src/Blog/Domain/Article/Shared/Model/Article.php</comment>
    Domain model/aggregate root

  * <comment>src/Blog/Domain/Article/Shared/Event/ArticleCreated.php</comment>
    Domain event emitted after creation

  * <comment>src/Blog/Domain/Article/Shared/Exception/ArticleAlreadyExists.php</comment>
    Domain-specific exception

The Domain Service features:
  * Single responsibility (one use case)
  * __invoke() method for simplicity
  * Pure domain logic, no infrastructure
  * Validates business rules
  * Returns aggregate with events

The Domain Model features:
  * Aggregate root pattern
  * Encapsulates business logic
  * Emits domain events
  * Strong typing with value objects
  * Immutable where appropriate

The Domain Event features:
  * Captures state changes
  * Immutable data
  * Carries all relevant information
  * Used for eventual consistency
  * Enables event sourcing

The Exception features:
  * Domain-specific errors
  * Meaningful business messages
  * Translation key support
  * Contextual information

Common domain services generated:
  * CreateArticle → ArticleCreator
  * UpdateArticle → ArticleUpdater
  * DeleteArticle → ArticleDeleter
  * PublishArticle → ArticlePublisher
  * GetArticle → ArticleGetter

Example business logic:
<info>public function __invoke(
    ArticleId $articleId,
    Title $title,
    Content $content,
    AuthorId $authorId,
    \DateTimeImmutable $createdAt,
): Article {
    // Business rule: Check uniqueness
    if ($this->repository->existsByTitle($title)) {
        throw new ArticleAlreadyExists($title);
    }
    
    // Create aggregate
    $article = new Article(
        id: $articleId,
        title: $title,
        content: $content,
        authorId: $authorId,
        status: ArticleStatus::DRAFT,
        createdAt: $createdAt,
    );
    
    // Domain event will be emitted
    return $article;
}</info>
